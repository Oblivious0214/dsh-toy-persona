# 人设音色与表情包改造计划

工作分支 `feat/persona-media` 从 `feat/composer-persona-picker` 建立。当前先完成分支准备；已有 0.3.1 行为继续保留，媒体绑定未接入运行逻辑。

每角色拟增加媒体偏好：Fish 音色 ID、偏好图库、表情发送频率、绘图参考和工作流。人设保存这些偏好；Fish、dsh-meme 和生图插件执行各自能力；QQ 皮肤负责展示。

偏好必须按会话读取，切换 A 会话的角色不得更改 B 会话的音色或图库。历史消息的语音应绑定生成时角色，避免重播时串音色。角色字段不存 API Key，不修改模型选择、工具权限或插件组合。插件缺失时应提示并保留可用的文本对话。

先实现偏好持久化与设置表单，再接 Fish 的单请求音色和 dsh-meme 的会话选择接口。若当前上游只有全局设置，应增加会话接口，不用反复改写全局配置实现切换。

完整推荐清单见工作区 `dsh-plugins/ENHANCEMENTS.md`。
