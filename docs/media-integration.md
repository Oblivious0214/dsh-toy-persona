# 人格音色、表情偏好和默认头像

## 表情偏好

仅在只读 `GET /dsh-memes-api?tag=__persona_switcher_catalogue_probe__` 返回 dsh-meme 的完整图库、标签结构后显示「表情偏好」按钮，初始隐藏。打开设置、窗口获得焦点、页面重新可见及每 30 秒复查；404、停用、权限错误、格式不符或网络失败均隐藏。停止插件后再次检查会隐藏入口，已保存的偏好保留。

使用 dsh-meme 0.1.64 现有接口，按 `packId` 读取每个图库的真实标签；额外传一个空结果标签筛选，避免为了查看标签传输整个图片索引。全程仅 GET，不修改原版插件、全局发送方式、启用图库或陪伴提示词。

弹窗提供多选优先图库、多选标签、发表情频率、补充提示词和提示预览。移除顶部说明和标签浏览下拉框，标签自动汇总勾选图库；未勾选图库时显示全部图库标签，改变图库不会丢弃已选标签。保存、清空偏好后保存、取消分别对应写入、解除、放弃草稿。已移除图库仍显示为不可用，已有选择可清除。空图库和空标签有对应提示。弹窗最多 480px，窄屏内滚动。

角色元数据 JSON 值为 `memePreference: {"packs":[{"id":"...","name":"..."}],"tags":["..."],"prompt":"...","frequency":"low"}`。最多 50 个图库、100 个标签、4000 字补充提示词；名称最多 256 字，不含控制字符。旧角色缺省为空偏好，旧客户端省略整个字段时保留，传 null 清除；人设正文、音色、头像保持兼容。

频率选项为 `default / low / medium / high / off`，对应跟随 dsh-meme、低频、适中、高频、不主动发；off 允许用户明确要求时使用。默认或省略 frequency 时不额外注入频率规则；清空偏好恢复默认。已检查安装的 dsh-meme 0.1.64 源码和管理 API：仅有全局 `setPromptEnabled / setSendMode`，没有频率接口，不用这些全局开关模拟角色频率。当前频率通过精简角色提示词表达，并非硬性计数或概率限制。生成文本仅保留优先图库名称、标签、频率和补充文字，不重复插件投递规则。

偏好随当前会话的角色提示一起注入，保存后立即刷新已绑定该角色的会话；重启后随角色恢复。换人设或取消人设会替换、清除原偏好。这是提示词层面的优先选择，不强制过滤候选，也不为 send_meme 增加参数；仍遵守 dsh-meme 的图库启用状态、发送方式和渠道规则，没有合适候选时允许用文字回应。

### DSH 与 dsh-meme 的兼容

在 DSH `system-prompt/assemble` 的外层监听中等待原插件生成提示，再仅适配当前 Agent 的 `dsh-expression:companion` 段。使用 DSH 已支持的 `{global:true,prepend:true}` 与当前组装上下文的 `agent`，不依赖插件加载顺序，不重组 Agent、不改模型、工具、权限或其他提示段。修改只存在于本次会话的组装结果，不写原插件文件和全局配置。

角色频率非默认时，移除已核实的 dsh-meme 0.1.64 Web/IM 内置主动斗图措辞，保留描述匹配、原生图片投递、QQ 路径要求、纯文字/图片模式等规则；角色提示明确频率优先于通用主动建议。任意全局自定义提示不做猜测式删除，而保留在“仅沿用与当前角色频率相容的要求”下，并明确角色频率优先；全局发送方式和渠道限制仍有效。

未绑定角色、默认频率、选择跟随、取消人设、诊断无 Agent 或子 Agent 时，原组装结果保持不变；dsh-meme 没有注入陪伴段时不凭空创建。保存角色后刷新已绑定角色提示，下一次组装读取新设置；已开始组装的请求保持其捕获的频率版本。监听随人格插件卸载自动移除。同一会话重建 Agent 后会在新的 Agent 作用域重新绑定，且不作为用户切换人设通知。

本机真实组件验证记录为 `work/persona-meme-compat-20261028/host-compatibility.json`。实际使用 DSH 的 Cordis、作用域与系统提示注册表，以及安装的原版 dsh-meme 陪伴提示代码，未启动真实模型、消息平台或设备。频率仍为模型指导，不是硬性的概率限流。

编辑已有角色右上角可设为或取消默认，即时写入 `persona-switcher.defaultRole`（空字符串表示无默认）。角色库仅为该角色显示「默认」标记。默认只作用于新建会话的首次创建，不替换旧会话、已记忆的人设或明确选择“不使用角色”的状态；更改或清除默认也不会回溯改绑。

角色库通过只读 `GET /fish-tts/config` 检测已启用的 Fish TTS，响应需包含音色字段；插件不存在、停用或接口不可用时隐藏音色按钮。打开设置、窗口获得焦点、页面重新可见及每 30 秒复查一次；卸载设置页时取消检查。

检测通过后，角色行显示「绑定音色」，打开独立对话框填写 Fish 音色 ID；底部左对齐，按顺序提供「取消」「试听」「保存」。可在保存之前试听当前输入，试听不会保存绑定；留空保存解除绑定，取消不写入。保存前读取最新角色，以保留其他窗口修改的人设文字。角色编辑区不再显示音色、试听语句或试听按钮，但保存文字时保留已有媒体字段。

弹窗最大宽度 320px，标题为左上角的「绑定音色」，音色 ID 使用输入框占位文字，不再单独占一行。三个按钮均高 28px，并随可用宽度收缩；浏览器回归加载宿主真实按钮组件和 CSS，检查浅深色、标题偏移和按钮边界。

弹窗内「试听」使用当前音色 ID 输入和角色既有试听语句；旧角色没有试听语句时使用内置示例。音色 ID 为空时不可试听；生成期间禁用输入和保存，关闭弹窗停止播放或取消待播放音频。试听会调用已配置的 Fish 服务，可能消耗额度。生成完成或失败后恢复原音色；若检测到其他窗口已改音色，则不覆盖。

从人设菜单选择人格、切回对应会话、窗口重新获得焦点时，将绑定音色同步到 Fish 全局默认值。直接输入 `/role` 的变化由当前页面轮询检测。音色留空或使用部署人设时不修改当前音色。Fish 不可用时角色仍可使用，界面显示同步失败。本版针对 Web/桌面界面，不提供无浏览器会话的自动音色同步。

原版 Fish 无需修改：调用 `GET/PUT /fish-tts/config`（仅写 voice 字段）及 `POST /fish-tts/synthesize`。当前页面的试听与音色同步串行执行。全局音色由所有会话共用，多窗口同时合成不保证隔离，旧消息新合成时使用当前默认音色。

角色库每行提供设置、更换、清除头像，独立于立绘。支持 1 MB 以内 PNG、JPEG、WebP；客户端检查图片尺寸，聊天中居中裁切显示。QQ 首次为会话取得人格头像后，保存该会话默认值；更换或清除角色默认头像不影响已经保存的会话。没有头像的旧会话首次接入此功能时，也会按当时绑定的人格取得默认头像。

QQ 头像优先级：手动会话头像 → 已保存的人格会话头像 → QQ 全局默认头像 → 内置头像。更换已有对话的头像仍通过 QQ 的头像编辑入口。

## 人格 HTTP 接口

以下使用默认前缀 `/persona-switcher/`，QQ 本次适配也使用该前缀。

- `GET /roles`、`GET /role?id=<roleId>`：角色对象增加 `voiceId`、`voicePreviewText`、`avatar`（本机图片 URL 或 null）。音色字段保存在 ROLE.md 元数据中，不进入人格正文。
- `POST /role`：接受 `voiceId`（最多 256 字、无控制字符）、`voicePreviewText`（最多 300 字）。省略字段时保留原值，空字符串明确清除。
- `POST /avatar?role=<roleId>`：JSON `{ "image": "data:image/png;base64,..." }`，返回 `{ "ok": true, "avatar": "/persona-switcher/avatar-file/..." }`。
- `DELETE /avatar?role=<roleId>`：清除角色默认头像，返回 `avatar:null`；保留历史会话引用。
- `POST /session-avatar`：JSON `{ "sessionId": "..." }`。从实际绑定或已记忆的人格取头像，仅首次写入会话默认值。返回 `{ "ok": true, "sessionId": "...", "avatar": "data:image/..." }`；没有可用头像时返回 null，允许之后重试。
- `GET /session-avatar?session=<sessionId>`：只读已保存的会话头像，不创建绑定。
- `GET /avatar-file/<filename>`：提供图片，使用不可变文件名缓存。

头像文件与绑定记录保存在 `DSH_HOME/persona-switcher/avatars/`。旧图片保留以支持历史会话引用，目前不自动清理。工具、模型、权限设置不受影响。

## QQ 接口

QQ 调用 `/session-avatar`，缓存已确认的会话默认值。未找到人格或头像的会话按需重试；插件缺失或请求失败时沿用 QQ 默认展示。

客户端提供 `QQImageRuntime.setPersonaAvatar({sessionId,image})`，以及 document 事件 `qq-skin:persona-avatar`，事件 detail 使用同一结构。只接受校验过的 PNG/JPEG/WebP data URL 或 null，手动会话头像始终优先。此接口仅更新当前页面显示；持久化来源由人格 HTTP 接口管理。

## 验证

人格回归测试覆盖音色字段兼容保存、试听恢复、错误恢复、头像上传和会话快照。QQ 测试覆盖缺失接口、错误会话、非法图片、过期请求、卸载和手动头像优先级。浏览器验证使用真实人格 UI、QQ 头像运行时和模拟服务，不调用真实语音或消息平台。
